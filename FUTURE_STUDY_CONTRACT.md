## Study A: controlled historical comparison

**Population and target.** A single frozen admitted game/event universe with explicit source exclusions, NBA-only canonical identities and consistent target units. Primary target remains home margin per 100 combined possessions. Report coverage against the scheduled universe; the matched-only contrast is secondary to the prospective all-opportunity assessment.

**Factors.** Accounting {legacy-row implementation, reconciled implementation}; update {prior-season, weekly}; calibration {frozen offset, development-only intercept+slope}. All eight cells use the same participation projection and issuance convention. Preserve the historical legacy implementation as a comparator, without changing canonical legacy outputs. Keep actual-participation results as a separately labelled oracle diagnostic.

**Two fairness questions, separately reported.** A controlled estimator contrast normalizes the training objective, target scale, sample weights and penalty/prior semantics before matching regularisation. A tuned-system contrast gives each implementation the same chronological tuning folds, budget and candidate selection rules. The same numeric lambda across different objectives/target scales is not inherently equal regularisation. Report objective definitions and transformed penalty units explicitly. Where row-versus-possession observations cannot share identical support, name the changed observation/selection mechanism; do not claim a pure denominator effect.

**Leakage and tuning.** Folds are grouped by game date, with every training/tuning/calibration source earlier than issuance. No current/final-season participation or revised source value is used as if contemporaneously available. Parameters and fitting choices are selected only from an already declared development segment. 2023-24/2024-25 results are exposed historical diagnostics; no cell selected on them is called an untouched validation result.

**Baselines.** Retain home-only and the prior player-rating controls. Add competitive calibrated team-strength and player-rating controls using the same source availability and participation. Freeze candidate model classes and chronological search budgets after the primary-literature review, before new outcomes. Optional market controls must use archived prices at the same issuance cutoff; no closing-line comparison may justify an earlier forecast. Unavailable markets remain unavailable.

**Inference.** Primary paired squared-error difference; display RMSE and MAE. Include interval score, coverage, width, tail losses, scheduled/matched coverage and season/quality strata. State the primary contrast family and simultaneous inference/multiplicity procedure before fresh results. Separate fixed-prediction uncertainty, temporal/team clustering and pipeline/model-refitting uncertainty. The current supplement only addresses one fixed-prediction calendar sensitivity, so it does not close this study.

**No forced positive result.** If fair regularisation/calibration removes the apparent accounting benefit, retain that result and revise the contribution to comparison integrity. A null test alone is not equivalence; practical equivalence requires a domain-derived margin and adequate precision.

## Study B: genuine pregame, scheduled-game validation

Each opportunity needs canonical game/teams, scheduled tip-off and revisions, UTC issuance time, model/config/input hashes, training cutoff, source available-at timestamps, projected participation, forecast/interval, quality flags, and an independently controlled receipt proving the record predates tip-off. Produce predictions for every scheduled game or an explicit unavailable state with a declared simple fallback. Record postponements/cancellations and outcome corrections. A game enters scoring only after the declared label/correction horizon matures; identity/source failures remain visible.

The upcoming 2026-27 regular season can provide future observations, but its complete-season outcome cannot exist by Dec. 4, 2026. An early-season study is a different horizon and must be stated as such. Do not promise a full-season confirmation in the invited manuscript.

**Precision gate.** Estimate clustered loss variability from declared development or exposed pilot data. Set the smallest useful loss reduction from the workflow's consequences, not the desired grade. Simulate power/interval precision across calendar/team/season dependence and missing forecast rates. Record required independent mature blocks, anticipated calendar feasibility and a futility rule. If the required precision cannot mature by the manuscript deadline, report an appropriately limited interim descriptive result or defer the claim. No arbitrary game count qualifies evidence.

## Study C: analyst review allocation

The bounded decision is which pregame forecasts receive human review under a measured review budget. Select cases using issuance-time source quality, participation uncertainty or model disagreement only. Also report total all-opportunity loss, review coverage, unavailable/fallback outcomes, time and failure cases.
